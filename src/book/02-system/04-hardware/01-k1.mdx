The [Booster K1](https://www.booster.tech/) is a kid-size humanoid robot made by Booster Robotics, and is the robot NUbots currently competes with. The previous robot, the NUgus, is documented in the [archive](/archive/nugus/specification).

Unlike the NUgus, the K1 ships with its own firmware, **BoosterOS**, which handles low-level control, walking and getting up. Our code talks to BoosterOS through the [Booster Robotics SDK](https://github.com/BoosterRobotics/booster_robotics_sdk). See the [Motion](/system/subsystems/motion) page for how this fits together.

## Overview

| Specification      | Value                                     |
| ------------------ | ----------------------------------------- |
| Height             | ~95 cm                                    |
| Weight             | ~19.5 kg                                  |
| Degrees of freedom | 22 (6 per leg, 4 per arm, 2 in the head)  |
| Max. peak torque   | 60 N·m                                    |
| Joint encoders     | Dual encoders                             |
| Battery            | 5 Ah, ~80 min runtime walking at 0.4 m/s  |
| Computer           | NVIDIA Jetson Orin NX                     |
| Operating system   | Ubuntu 22.04                              |
| Camera             | Head-mounted stereo depth camera          |
| IMU                | 9-axis                                    |
| Audio              | Circular 6-microphone array and a speaker |
| Networking         | Gigabit Ethernet, Wi-Fi 6, Bluetooth 5.2  |
| Buttons            | 1 power button and 3 interaction buttons  |

The specifications are from Booster's datasheet, apart from the computer and operating system, which are those of the team's robots.

## Camera

The K1's head has a stereo depth camera. We only use one of its RGB streams, which BoosterOS publishes over DDS. See the [Input](/system/subsystems/input) page for details.

## Computing

The K1 used by the team runs an NVIDIA Jetson Orin NX. Code for it is built with the `orinnx` target; see the [Build System](/system/foundations/build-system) page. The Orin NX's GPU runs the [YOLO](/system/subsystems/vision) vision model using TensorRT.

When connecting to the robot, the username is `booster`.

## Buttons

Two of the interaction buttons, left and middle, are read by the [Sensors module](https://github.com/NUbots/NUbots/tree/main/module/input/Sensors), which emits button up and down messages that behaviours can use.
